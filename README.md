## 🎮 What Is Stronghold-Protocol?

Stronghold-Protocol blends two popular styles of play. The first is tower defense: enemies march along a path and you stop them by placing defenders in the right spots. The second is auto-chess: instead of controlling every unit by hand, you build a lineup before and between waves, and the units fight on their own once the round begins. The result is a game that is easy to pick up, tense to watch, and deep enough to reward planning.

The game is designed to be played in a web browser. That means the screen you see is a web page, and the game itself is a small program running quietly in the background on your own computer. You do not need to install a big desktop game, and you do not need an account on a gaming platform.

The project is a fan tribute. It is free, it is not sold anywhere, and it is not affiliated with the original game's creators or publishers.

## 🕹️ Your First Match

When the game loads for the first time, choose the single-player option so you can learn without pressure.

- **Look at the map first.** Before you place anything, study the path the enemies will walk. The best defenders are the ones placed next to a corner or a long stretch of road, because they get more time to attack.
- **Place a small number of units.** Start with two or three. Spreading your units too thin is the most common beginner mistake.
- **Watch the first wave closely.** You will quickly see where enemies slip through. That tells you exactly where to add more defenders next time.
- **Save some of your resources.** Placing everything immediately leaves you with nothing to react with when a stronger wave arrives.
- **Read what each unit does.** Units in this style of game fall into loose roles such as damage dealers, blockers, and support. Mixing roles works better than stacking one type.
- **Repeat and refine.** Each run teaches you something. A few short matches will teach you more than any guide.

Once you can survive several waves comfortably on your own, you are ready to play with other people.

## 🤝 Playing With Friends (1–4 Players)

Co-op is where Stronghold-Protocol shines. Up to four players can share a single match and defend together.

1. Start the game the same way you would for single-player.
2. Choose the multiplayer or co-op option on the main menu.
3. One player hosts the match and receives a room code or shareable link.
4. The host sends that code or link to friends through chat, email, or voice chat.
5. Each friend opens the game, chooses to join, and enters the code.
6. When everyone is in the lobby, the host starts the match.

A few practical notes for smooth sessions:

- Everyone should be on a stable internet connection. A wired connection is better than public Wi-Fi.
- Agree on roles before the match begins. One player handles early waves while another saves up for stronger units.
- Talk during the match. Short callouts like "left side is open" prevent most losses.
- If a friend cannot connect, have them leave and rejoin — the lobby will usually accept them on the second try.

## 🧠 Tips for New Players

- **Positioning beats raw power.** A modest unit in a good spot outperforms a strong unit in a bad one.
- **Do not chase every upgrade.** Focus on a small set of units you understand well before adding more.
- **Watch the enemy types.** Different waves bring different threats, and some units answer certain threats far better than others.
- **In co-op, divide the map.** Two players covering the same lane waste resources; two players covering different lanes rarely lose.
- **Give yourself a warm-up match.** A single-player round before a group session gets your reflexes and planning warmed up.

## 🔧 Troubleshooting Common Issues

**The game page will not load.** Check that the small background window is still open. If you closed it, start the program again and reopen the page.

**The browser shows an error about the connection.** Close the browser tab, make sure the background program is running, and open the address again.

**Windows warns about the file.** This is a standard warning for programs downloaded from the internet. Choose the option to keep and run the file.

**Friends cannot join my match.** Make sure the host has not closed the background window, and share the code again exactly as it appears, with no extra spaces.

**The game runs slowly.** Close other browser tabs and any other programs you are not using, then reload the page.

**My unit placements feel delayed.** A slow or crowded network can cause a short delay. Playing on a wired connection usually fixes it.
